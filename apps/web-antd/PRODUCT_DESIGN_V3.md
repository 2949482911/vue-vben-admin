## 1. V2 复盘：不足与本次调整

V2（PRODUCT_DESIGN_V2.md）解决了"有没有"的问题：批投、托管规则、统一看板、素材分析、AI 助手的概念都给出了方案。但对照行业标杆（引力/创量/热力/神策/数数），存在以下结构性不足，V3 逐一调整：

| # | V2 的不足 | 严重度 | V3 的调整 |
|---|----------|--------|-----------|
| 1 | 以"功能点补齐"组织，缺乏一条 **广告全生命周期主线**，资产/搭建/投放/监测/归因/复盘彼此割裂 | 高 | 以生命周期 OS 为主线重新架构（第 4 章），每个阶段定义系统能力、AI 介入点、人工介入点 |
| 2 | AI 托管停留在 **规则引擎**（条件→动作），不是真正的 AI 智能体，无法对话、无法自我学习 | 高 | 引入 **AI 智能体体系**（第 7 章）：对话式投放助手、自动盯盘、智能诊断、策略推荐；引入自动驾驶 L1-L4 分级 |
| 3 | 无统一 **数据底座** 设计：归因、回传、行为数据、平台数据各自为政（数数/神策的立足点） | 高 | 数据底座（第 9 章）：采集、归因、指标仓库、用户粒度 ROI / LTV |
| 4 | 资产（素材/定向/标题/落地页）散落在平台功能里，未形成 **统一资产中心**（创量的"资产数据化"） | 高 | 六大资产中心（第 5 章），资产一次沉淀、多平台复用、效果回流标注 |
| 5 | 归因与行为数据割裂，无法回答"用户从点击到付费全链路"（热力/数数的核心价值） | 高 | 归因×行为打通：用户粒度 ROI、LTV、条件回传（第 9.2/9.3） |
| 6 | AI 对话式投放只是一段概念示意，无落地路径 | 中 | 落地路径：NLU → 意图解析 → 动作编排 → 审批 → 执行 → 反馈（第 7.2） |
| 7 | 无团队协作/审批/审计设计（创量多角色协作） | 中 | 协同与安全（第 10 章） |
| 8 | 测试覆盖窄（仅巨量/OPPO）、模板代码重复度高、枚举文件过大等架构问题 | 中 | 保留并在第 13 章深化 |

## 2. 产品定位与总体愿景

### 2.1 定位

```
V1 批投工具 → V2 效率平台 → V3 AI 驱动的全媒体投放数据中台
```

**一句话定位**：以 AI 投放助手为唯一中心入口，覆盖"洞察规划 → 资产准备 → 搭建投放 → 监控优化 → 归因回传 → 复盘迭代"广告全生命周期的全媒体投放数据中台。

**终极形态（全链路 AI 托管投放）**：用户在 AI 投放助手中以自然语言下达目标（如"帮我创建一个巨量应用下载广告，日预算 1000，目标成本 30"），AI Agent 通过 Tool 调用**自主完成全链路**：检索/生成素材与文案 → 匹配定向与落地页 → 构建媒体广告 → 配置监测回传 → 提交投放 → 自动盯盘优化 → 汇报结果。**人工仅做按风险分级的兜底审批，目标为无需人工干预**（对标引力引擎"AI 投手团队"、腾讯 AIM+"自动驾驶"叙事，但更彻底——不是"辅助人工"，而是"AI 主执行、人工兜底"）。

### 2.2 自动驾驶分级（借鉴引力引擎）

将 AI 自动化能力分级，产品按级演进、按级售卖：

| 级别 | 名称 | 系统能力 | 人工介入 | 对应模块 |
|------|------|----------|----------|----------|
| L1 | 手动辅助 | 批量搭建、模板复用、报表 | 每步操作 | 现有批投 |
| L2 | 规则自动化 | 规则托管（止损/预算/出价）、定时执行 | 配置规则后免盯盘 | 智能托管（V2 已完成） |
| L3 | 条件智能化 | Agent 检测异常→生成建议→人工一键确认 | 确认 Agent 建议 | 智能诊断+策略推荐 |
| L4 | 高级自动化 | Agent 自主执行（预算内、护栏内），仅超限时上报 | 异常/超限才介入 | 对话式投放+自动盯盘 |
| L5 | 端到端自治 | 目标驱动：给定 KPI，系统自建计划/自调/自关/自测 | 只定目标 | 目标托管（远期） |

> 产品路线按 L1→L5 渐进，每级都释放一部分人工，这是商业化的核心叙事（对标引力"AI 投手团队"）。

### 2.3 核心价值主张

1. **全媒体一个系统**：接入所有主流媒体，一个中台管理全部投放
2. **生命周期全自动**：从资产到复盘全链路自动化、AI 化
3. **对话式投放**：用自然语言操作投放系统
4. **每一分钱看得清**：归因×行为打通，用户粒度 ROI/LTV
5. **AI 投手团队**：7×24 自动盯盘、自动优化、持续进化

## 4. 广告全生命周期闭环（核心主线）

```
┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐
│①洞察规划 │→│②资产准备 │→│③搭建投放 │→│④监控优化 │→│⑤归因回传 │→│⑥复盘迭代 │
└────────┘  └────────┘  └────────┘  └────────┘  └────────┘  └────────┘
     ↑                                                                 │
     └──────────────── 策略/知识沉淀回流（AI 越用越强）──────────────────┘
```

### ① 洞察规划（AI 辅助决策）
- **输入**：历史投放数据、素材表现、市场大盘、竞品情报、客户目标（KPI/预算）
- **系统能力**：智能诊断（账户健康度）、竞品监测、市场态势感知、预算拆解建议
- **AI 介入**：生成投放策略草案（渠道组合、预算分配、人群建议）
- **人工介入**：确认策略方向（L3 前），L4+ 仅确认预算上限

### ② 资产准备（基建设置 — 资产中心）
- **输入**：产品信息、目标人群、平台规格
- **系统能力**：六大资产统一管理（素材/定向/标题文案/落地页/产品/人群），多平台规格自动适配，AIGC 素材衍生
- **AI 介入**：自动生成多版本文案、素材衍生、落地页智能生成
- **人工介入**：审核资产（合规）、选择素材方向

### ③ 搭建投放（投放执行）
- **输入**：策略、资产、账户范围
- **系统能力**：批量搭建（分配规则：统一/按账户/按项目）、模板复用、防错校验、分时分批投放
- **AI 介入**：对话式指令批量建计划（"帮我在巨量建 10 条应用下载计划，出价 30"）、优质计划复制
- **人工介入**：确认提交（可配置免确认）

### ④ 监控优化（智能托管 + Agent）
- **输入**：实时投放数据、成本/消耗/转化信号
- **系统能力**：规则托管（止损/预算/出价/起量）、异常检测（超成本/空耗/突降）、预测（起量、衰退）
- **AI 介入**：自动执行护栏内动作；生成诊断结论与建议
- **人工介入**：超限动作审批；查看日报告

### ⑤ 归因回传（数据闭环）
- **输入**：点击/曝光数据、激活/行为/付费数据
- **系统能力**：多模型归因、条件回传（按事件/设备/条件筛选）、SKAN 处理、Click-ID 追踪
- **AI 介入**：回传策略自动优化（用于媒体模型校正）
- **人工介入**：归因配置维护

### ⑥ 复盘迭代（数据分析）
- **输入**：全链路数据（投放+行为+收益）
- **系统能力**：统一看板、多维交叉分析、素材分析、报表自动化、用户粒度 ROI
- **AI 介入**：智能复盘报告（"本周 3 条计划超成本、素材 A 衰退 3 天"）、下一轮策略建议
- **人工介入**：确认下轮方向 → 回到①

## 5. 基础设施：六大资产中心

借鉴创量"资产数据化"与神策"资产分层"，把散落在平台里的资产统一为**资产中心**，一次沉淀、多平台复用、效果回流。

| 资产库 | 内容 | 关键能力 |
|--------|------|----------|
| **素材库** | 图片/视频/文案/组图，版本管理 | 标签体系（自动+手动）、审核状态、**投放效果回流**（CTR/CVR/消耗按素材）、**基因标注**（场景/色调/人物/文案风格）、AIGC 衍生入口 |
| **定向包** | 人群定向集合（年龄/性别/兴趣/地域/设备） | 跨平台复用、规格映射、定向效果评估 |
| **标题文案库** | 标题、描述、行动号召、落地页话术 | 多版本、A/B 打标、AI 文案生成、合规预检 |
| **落地页库** | H5/小程序/商城/下载页 | 页面模板、A/B 测试、转化监控、Click-ID 埋点注入 |
| **产品库** | 商品/应用/内容（卖点、价格、图集） | 卖点拆解、多平台商品映射（已具备 product_info 能力） |
| **人群包** | 自定义人群/相似人群/排除人群 | 跨平台上传、人群画像、相似扩散 |

**资产效果回流**：资产与投放计划建立关系表，任何素材/文案/落地页在哪个计划跑出什么效果，统一回流到资产卡片（对标数数"渠道×素材×时间段"下钻）。

## 7. AI 智能体体系（核心创新 · 产品主线）

> 对标引力引擎"AI 投手团队"。**Agent 原生架构**：对话式投放助手不是系统的一个功能，而是**唯一中心入口**——现有全部能力（资产检索/广告构建/监测配置/平台操作/数据查询）都被封装为 AI 可调用的 **Tool**，由 Agent 编排执行。规则引擎、数据仓库、归因回传都是为 Agent 决策服务的"器官"。

### 7.1 智能体全景

```
┌─────────────────────────────────────────────────────┐
│                  AI 智能体体系（AI 投手团队）          │
├───────────────┬─────────────────┬───────────────────┤
│ 对话投放助手    │ 自动盯盘 Agent    │ 智能诊断 Agent     │
│ (执行类)       │ (监控类)         │ (分析类)           │
│ NL→意图→动作   │ 7×24 规则+模型    │ 健康度/异常归因     │
│ 建计划/改价/关停│ 护栏内自动执行    │ 输出诊断+建议       │
├───────────────┼─────────────────┼───────────────────┤
│ 策略推荐 Agent │ 目标托管 Agent    │ 素材洞察 Agent      │
│ (决策类)       │ (远期 L5)        │ (内容类)           │
│ 预算倾斜/人群    │ 定 KPI→自建自调  │ 爆款识别/AIGC衍生   │
│ 建议           │ 自关自测         │ 基因库沉淀          │
└───────────────┴─────────────────┴───────────────────┘
```

### 7.2 对话式投放助手（落地路径）

**体验目标**：优化师用自然语言完成投放操作，AI 代替"找按钮"。

```
"帮我把巨量上 ROI 低于 0.8 的计划全部关停"
      │
      ▼
① 意图解析：动作=关停 │ 目标=计划 │ 条件=ROI<0.8 │ 平台=巨量
      │
      ▼
② 数据查询：Agent 调用报表 API 筛选命中计划（3 条：id、名称、ROI）
      │
      ▼
③ 执行预案：生成动作卡片（待确认/自动执行由权限与 L 级决定）
      │
      ▼
④ 审批/护栏：超限需人工确认；否则护栏内直接执行
      │
      ▼
⑤ 执行+回执："已关闭 3 条超成本计划，预计日省 ¥XXX，可撤销"
```

**技术要点**：
- **意图 schema 化**：将操作收敛为固定动作集（建计划/改预算/改出价/暂停/恢复/关停/复制/报表），NLU 输出结构化意图，动作集与现有 API 一一对应，保证安全与可控
- **上下文记忆**：会话内记住"当前账户/平台/时间范围"，减少重复表述
- **可撤销**：操作产生审计记录，支持一键回滚（改预算→恢复原值）
- **兜底降级**：无法解析的意图 → 转人工/给出候选指令模板（"你可以这样说：..."）

### 7.2.1 全链路执行示例（一句话创建广告）

> 这就是终极形态的"架子"要支撑的最小端到端闭环，也是阶段 0+1 的验收目标。

```
用户："帮我在巨量创建一个《XX游戏》应用下载广告，日预算 1000，目标成本 30，跑一周"
      │
      ▼
① 意图解析（意图 schema）：目标=应用下载 │ 平台=巨量 │ 产品=XX游戏 │ 预算=1000/日 │ KPI=CPA30 │ 周期=7天
      │
      ▼
② 任务规划（Plan）：[选素材]→[选文案]→[选定向]→[选落地页]→[构建广告]→[配置监测]→[提交投放]→[创建盯盘]
      │
      ▼
③ 工具执行（Tool 调用，每步可观测、可中断、可撤销）
   Asset Tool  "检索素材库：product=XX游戏, top by CTR(近7天)"  → 命中 3 条素材
   Asset Tool  "检索标题文案库 / AI 生成 5 版文案"
   Asset Tool  "检索定向包：历史跑量人群 / 生成默认定向"
   Asset Tool  "匹配落地页：应用下载页（无则提示补充）"
   Build Tool  "组装巨量广告参数 + 校验（预算/出价/合规）"
   Monitor Tool"生成监测链接(click_id) + 事件回传配置"
   Platform Tool "调巨量 API 创建（素材×文案组合 N 条）"
      │
      ▼
④ 兜底审批：高风险（预算>阈值/关停）需确认；护栏内自动执行
      │
      ▼
⑤ 创建盯盘任务（Control+Data Tool）：自动监控成本/ROI，超限自动止损
      │
      ▼
⑥ 汇报："已创建 6 条广告（3素材×2文案），预计日耗 ¥1000，已开启自动盯盘，详情点此查看"
```

关键点：**决策有据**（选素材必须基于效果数据）、**每步可观测**（执行卡片展示中间结果）、**人工可接管**（任一步可打断）。

### 7.3 自动盯盘 Agent（监控类）

- 周期执行（分钟/小时级）规则+模型双引擎
- **护栏机制**：日动作次数上限、单动作金额上限、全账户总额度、高敏操作（关停/大幅调价）强制审批
- 异常分类：超成本、空耗、预算撞线、消耗突降/突增、素材衰退、审核被拒
- 每个动作产出结构化日志：时间、对象、原因、动作、结果、可回滚性（沿用现有 HostingLogDrawer 模式）

### 7.4 智能诊断 Agent（分析类）

- 账户健康度评分（消耗效率/成本达标/素材新鲜度/预算利用率）
- 异常归因："今日消耗同比降 40%，原因：2 条主力计划关停 + 素材 A 衰退"
- 输出可读诊断报告（对齐神策"异常指标预警"）

### 7.5 Agent 安全与治理（重点）

| 机制 | 说明 |
|------|------|
| 权限映射 | Agent 动作受 RBAC 约束，只执行授权账户的操作 |
| 审批流 | 高敏动作（关停/预算变更>阈值）走审批；审批人、渠道可配 |
| 执行护栏 | 金额/频次/范围三重上限，防失控 |
| 全程审计 | 每次 Agent 动作记录到操作审计（操作人=Agent，附决策依据） |
| 手动接管 | 任一 Agent 动作可被人工一键撤销/覆盖 |
| 灰度上线 | Agent 先"建议模式"运行 N 天，人工采纳率达标后才转"执行模式" |

## 8. 智能托管引擎（升级）

V2 已落地规则引擎（止损/预算/出价/起量 + 执行模式 + 指标比较），V3 在三个方向升级：

### 8.1 从"规则"到"模型"
- 规则引擎负责确定性场景（成本>X 持续 N 分钟→关停）
- 引入**预测模型**覆盖不确定性场景：
  - **起量检测**：素材 CTR/消耗增速模型，识别"即将爆量"素材并自动追加预算/复制计划（对标创量"起量素材自动追投"）
  - **衰退预测**：素材 CTR 连续下降趋势建模，提前预警替换（对标创量"低效素材自动清理"）
  - **空耗检测**：消耗>X 且转化=0 的组合判定
  - **预算分配优化**：跨账户/跨计划，将预算向高 ROI 计划倾斜（对标创量"智能出价/止损"）

### 8.2 触发条件补充（补齐 V2 4.1 未列全的）
- 分时段出价：凌晨低效时段自动降价
- 竞争环境响应：CPM 突涨→提示降出价/换素材

### 8.3 执行动作扩展
- 新增：预算重分配、素材替换、计划复制、时段调整、账户间流量再平衡（避免内部抢量，对标创量"差异化批量建投"）

## 9. 数据底座与分析层

> 借鉴数数科技"营销数据×用户行为闭环"、热力引擎"归因+行为+ROI"、神策"分析/受众/策略三引擎"。

### 9.1 数据采集
- 平台投放数据（Report API 定时拉取，已有 reportApi/metricApi）
- 用户行为数据（SDK 埋点：激活/注册/付费/事件，已有 OCPX 事件体系，扩展为完整埋点）
- 广告回传数据（已有 40+ 平台回传对接）

### 9.2 归因引擎（升级）
- 多模型归因：last-click / 多触点加权 / 模糊归因（IP+UA，借鉴引力引擎）
- **Click-ID 全链路追踪**：曝光→点击(click_id)→落地页埋点→转化匹配（补 V2 4.6）
- **条件回传**：按事件/设备/条件筛选回传数据（借鉴热力引擎，用于媒体模型校正）
- SKAN 处理（iOS 归因时延与数据回传）

### 9.3 数据仓库与指标体系
- 统一指标仓库：CPM/CPC/CTR/CVR/CPA/ROI/ROAS/LTV，全局统一口径（借鉴数数）
- **用户粒度 ROI**：归因 ID × 用户行为 × 收益，算出"每个用户从哪条广告来、花了多少钱、带来多少收益"（LTV/ROAS 按渠道/素材/时间段下钻）
- ID-Mapping：设备/账号跨端打通

### 9.4 分析层
| 模块 | 能力 | 现状 |
|------|------|------|
| 统一看板 | 总消耗/总转化/总 ROI/曝光、平台对比、趋势、账户 Top、素材排行、告警列表 | ✅ 已落地（unified） |
| 多维交叉分析 | 时间×平台×账户×素材×定向×落地页，指标自定义（利用 metricApi） | ⚠️ 部分 |
| 素材分析 | 概览/生命周期/排行/对比/标签/基因分析 | ⚠️ 部分（概览+生命周期已落地） |
| 报表自动化 | 日报/周报/月报模板、定时推送（企微/钉钉/邮件）、PDF/Excel 导出 | ⚠️ 需强化 |
| 告警中心 | 独立告警页：规则配置（超成本/空耗/预算撞线/素材衰退/账户异常）+ 通知渠道 | ⚠️ 需补（现内嵌看板） |
| 智能复盘 | AI 生成周报/月报诊断与下轮建议 | ❌ 新设计 |

## 11. 创新需求设计

在 V2 第 5 章基础上，结合标杆重新收敛为 8 大创新点：

### 创新 1：AI 对话式投放（自然语言操作系统）
详见 7.2。核心是"意图 schema 化 + 动作集收敛 + 护栏执行"，让 AI 对话从演示走向生产。

### 创新 2：投放策略 DSL + 策略自动进化
- 用类 JSON/DSL 描述策略（阶段、条件、动作、时限）——沿用 V2 创新 1
- **新增"自动进化"**：策略命中后记录执行效果，低效策略自动标记并提示改写；沉淀为可复用策略模板库（创量"策略复用"）

### 创新 3：素材基因库 + AIGC 素材衍生
- 素材打基因标签（背景/人物/文案风格/构图），与效果数据关联 → "蓝色背景+真人出镜+价格锚点"平均 CTR 3.2%
- AIGC 衍生：输入爆款素材，替换物品/人脸/语音/文案生成多版本（借鉴创量 AIGC 素材复制），进入多账户投放测试
- 文案自动生成：卖点×人群 → 多版本标题/行动号召（已具备产品卖点结构）

### 创新 4：归因×行为一体化的用户粒度 ROI
数据底座打通后，从"看报表"升级为"看用户价值"：按渠道/素材/时间看 LTV 与 ROI，支撑预算向"高价值用户来源"倾斜。

### 创新 5：智能预算分配与流量再平衡
全局预算池 → 按 ROI/转化效率自动分配，避免多账户内部抢量；支持"分时分批 + 错峰抢流"。

### 创新 6：实时态势大屏
V2 创新 2 保留，补充：实时消耗 vs 昨日同时段、行业大盘（CPM/CPC）、竞争热度、预警信号（CPM 突涨）。

### 创新 7：竞品情报模块
素材监控（三方数据：有米云/DataEye）、投放策略推测、我方 vs 竞品对比（消耗级别/素材风格/出价区间）。

### 创新 8：投放知识沉淀（AI 越用越强）
- 案例库：历史"问题→诊断→动作→效果"沉淀为案例
- 方法论：AI 复盘报告沉淀为团队 SOP
- 反馈闭环：Agent 动作的效果回流，训练/优化预测模型与推荐策略

> 注：ADX 双向联动（V2 创新 4）保留为远期差异化，不与本阶段竞争重点冲突。

## 15. 实施路线图

> 原则：**先搭 Agent 骨架，再按"AI 可调用"标准逐能力封装成 Tool，最终覆盖全链路**。不是"先人工工具后 AI"，而是"架构一开始就是 AI 主执行，人工兜底"。

```
阶段 0：Agent 运行时骨架（搭架子，P0）
├── Tool 注册中心（Tool schema + 执行器注册，平台无关）
├── 对话层：意图解析（意图 schema 化，固定动作集）
├── 任务规划器（Plan-and-Execute：复杂目标自动拆解）
├── 执行器 + 流式结果反馈 + 护栏（权限/审批/审计/可撤销）
└── 前端：AI 投手助手升级为"执行入口"（对话 + 执行卡片）

阶段 1：第一批工具 + 端到端打通（P0，里程碑：一句话创建广告）
├── Asset Tools：素材检索（按产品/历史效果）、文案检索/生成、定向检索、落地页检索
├── Build Tools：广告参数构建 + 校验
├── Monitor Tools：监测链接生成 + 事件回传配置
├── Platform Tools：创建广告（巨量/OPPO 先行）
└── 验收：对话"创建 XX 应用下载广告"→ AI 自动选素材/文案/定向 → 预览确认 → 创建成功

阶段 2：自动盯盘（P0，里程碑：自动止损）
├── Data Tools：实时报表查询
├── Control Tools：暂停/恢复/改价/改预算/复制（统一 PlatformApiAdapter）
├── 盯盘 Agent：周期执行 + 异常检测 + 护栏内自动动作 + 日志
└── 验收：超成本广告被自动止损，日志/统计正确

阶段 3：感知层（并行，支撑 AI 决策）
├── 媒体数据同步（PlatformReportFetcher → ad_report_data）
├── 看板补接口（material_rank / alerts）
└── 素材效果回流（AI 选素材的决策依据）

阶段 4：商业化收口（对标创量/引力雏形）
├── 素材分析后端 + 告警中心独立化 + 操作审计 + 订阅推送强化
├── 用户粒度 ROI（归因×行为）
└── 竞品情报 / 素材基因库 / 策略知识沉淀（P2 按需）
```

**里程碑建议**：阶段 0+1 完成即打通"全链路 AI 托管投放"的第一条端到端主线（对话→建广告）；阶段 2 完成达成"自动盯盘无需人工"；阶段 3 补齐 AI 决策的数据感知；阶段 4 交付商业化雏形。
